App icon

A four-hop route (traceroute / AS path) ends in a destination that emits ping rings. White on a deep blue gradient, no text, full-bleed 1024×1024 (docs/icon.svg). The rings stay readable down to Spotlight size; the route reads as “path across a network”.

States

Every tool shares the same four non-happy states, rendered with ContentUnavailableView or an inline banner.

Loading

“Fetching routes from RIPEstat…” — skeleton header, progress spinner, Cancel.

Offline

“You’re offline.” Banner under the target bar; Start/Map disabled; recents still usable.

Not routed

“10.0.0.0/8 is a private range and isn’t announced in BGP.” Detected locally, no request.

Error

“Couldn’t resolve example.invalid” / “RIPEstat is busy (429)” — message + Try Again.

Legend & notes

Origin AS — rightmost column, tinted fill. Several origins (MOAS) stack here with a warning chip.

AS node — ASN + short holder name. Dot = this AS is itself a RIS peer (a path starts here).

Collapsed bucket — ASes beyond the per-column limit. Tap to list them; “Top 6 / 12 / 30” menu changes the limit.

Edge width = 1.5 + 6·√(paths on edge ÷ all paths). Edges point toward the origin.

Dashed arc = lateral edge (same column). Blue = paths through the selected AS; other nodes dim.

< 80 ms 80–200 ≥ 200 timeout

RTT colours used in ping rows, chart points and hop averages (always paired with the number, never colour alone).

  • Navigation: compact width → TabView (Ping · Traceroute · BGP Map); regular width → NavigationSplitView with a sidebar of tools + recents, and an .inspector for AS details.
  • Cross-links: long-press a traceroute hop → Ping this hop / Map in BGP; tap a hop’s ASN badge → BGP Map for that IP.
  • Data: probes run on-device (unprivileged ICMP sockets). BGP data and hop ASNs come from the public RIPEstat Data API. No accounts, no analytics, no tracking.
  • Type & colour: SF Pro / SF Mono (system), system colours, Dynamic Type, Dark Mode. Numbers use monospaced digits so columns don’t jitter while updating.
