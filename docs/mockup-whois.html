Navigation & data

PingTraceBGPWhois

Fourth tab “Whois” (person.text.rectangle), appended so ⌘1–3 keep their meaning; Whois is ⌘4. It opens on your own IP, so “my IP” needs no typing.

registryfrom descriptionfrom AS24940from RIR statistics

Provenance, always visible. RIPE-style records carry an org handle, not a name; LACNIC has no records. Fallback values are labelled where they appear and in the export.

  • Both IP families: two whats-my-ip calls over NWConnection pinned with NWProtocolIP.Options.version (.v4 / .v6). URLSession can’t force a family. Skipped when NWPath reports no IPv6; URLSession fallback if both fail.
  • Data: RIPEstat only — whois, network-info / prefix-overview / as-overview, abuse-contact-finder, rir-stats-country, as-names, maxmind-geo-lite. ARIN IPv6 addresses retry with the covering prefix.
  • Cross-links: Traceroute hop menu and header, Ping header, BGP AS details and toolbar menu → Whois. Whois → Ping, Traceroute, Map in BGP, and origin-AS drill-down.
  • Privacy: label stays “Data Not Collected”. Your public IP lives in memory only and is forgotten on network change. Local addresses never leave the device. Screenshot mode injects fixed addresses.
